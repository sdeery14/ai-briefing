# ADR 004 — Evidence-first multi-dimensional editorial ranking

**Status:** Proposed

## Context

Popularity and model enthusiasm are unreliable proxies for professional importance. Significant science can be immature; useful tools can be incremental.

## Decision

Assess impact, evidence, novelty, relevance and maturity separately, with 0–4 scales, citations, uncertainty and a four-class disposition. Ranking for placement is distinct from classification.

## Consequences

More explanation and calibration work is required; editorial policy and prompt changes need human review and regression evidence.

## Revisit when

A specific observed requirement or failure invalidates the current tradeoff. Changes to an accepted decision require a superseding ADR.
